# Công cụ tính khối lượng thép (vòng 1)
Chạy: mở `index.html` bằng trình duyệt (không cần server). Kiểm thử: `node js/tests.js`.

Đã có: thép tấm, ống tròn, hộp vuông/chữ nhật, V đều/không đều, thép dẹt/tròn/vuông; chọn vật liệu và khối lượng riêng tùy chọn;
tìm kiếm; yêu thích; gần đây; bảng vật tư (nhân đôi, xóa, sửa số lượng, xuất CSV mở bằng Excel); in; kiểm thử trong ứng dụng.

Lưu ý: bán kính góc hộp (EN 10219) và r1 của thép V cần đối chiếu bản tiêu chuẩn/bảng tra gốc. Thép I/U (UPN, IPE, HEA, HEB...) và HVAC thuộc vòng sau.
Thêm calculator: thêm một mục vào `js/calculators.js`, giao diện tự sinh.
